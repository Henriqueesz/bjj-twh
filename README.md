# 🥋 BJJ-TWH Academy

Bem-vindo ao **BJJ-TWH Academy**!  
Este é meu **primeiro projeto pessoal**, no qual busquei unir minha paixão por **programação** com o amor pelo **esporte**.

O projeto traz ideias pensadas para **amigos atletas**, como um **catálogo de posições** e **drills**, ajudando a melhorar a prática e o desempenho no **Jiu-Jitsu**.  

Ainda está em desenvolvimento, mas minha meta é criar uma plataforma **útil, intuitiva e divertida** para quem ama o esporte.

---

## ⚡ Funcionalidades

- 📚 Catálogo de posições de Jiu-Jitsu  
- 🏋️ Drills e exercícios para treino  
- 🏠 Páginas implementadas: **Home**, **Profile** e **Register**  
- 🎨 Interface responsiva com **Bootstrap**  

---

## 🛠 Tecnologias Utilizadas

- **HTML5** – Estrutura da aplicação  
- **CSS3** – Estilização das páginas  
- **JavaScript** – Funcionalidades interativas  
- **Bootstrap** – Framework para desenvolvimento responsivo
